# 现场测光界面参考与本轮方向

2026-11-23，基于 `0.4.0-beta1` 的独立 `ui/photographer-controls` 分支，候选试用版为 `0.4.0-beta2 (versionCode 10)`。本轮只调整 Android 界面、交互入口和测试，不合并第三方的测光、色彩或曝光模型。

## 获取和实际查看的项目

### Material Lightmeter

- 仓库：https://github.com/ScaredCube/m3_lightmeter
- 查阅版本：`c6c52981ee443aa438c04aaa5634d9efbcaa48c8`
- 直接查看了仓库内的 Android 浅色、深色、ISO 选择和设备档案截图，以及 Flutter 布局源码。
- 值得参考：底部主要测量入口、清晰的 ISO 和设备参数入口、不同页面的信息层次。
- 不照搬：偏小的取景缩略图、占空间较多的卡片，以及不适合当前原生结构的 Flutter／Material 依赖。
- 仓库附带 GPL-3.0 许可证。本轮不复制其源码或图片。

### Lightstop

- 仓库：https://github.com/the-waterwheel/lightstop
- 查阅版本：`bd6cb67b0ef0f5d64949377c2729d2448c5dae87`
- [普通取景](https://github.com/the-waterwheel/lightstop/blob/bd6cb67b0ef0f5d64949377c2729d2448c5dae87/docs/screenshots/v0.7.0/normal-average.png)和[简洁模式](https://github.com/the-waterwheel/lightstop/blob/bd6cb67b0ef0f5d64949377c2729d2448c5dae87/docs/screenshots/v0.7.0/clear.png)。

- 值得参考：大取景、明确的当前参数、独立测量操作、简洁与详细工作流分离。
- 不照搬：自定义刻度与小图标的学习成本，以及把全部辅助工具塞进现场主路径。
- 仓库附带 Apache-2.0 许可证。本轮不复制其源码或图片。

### FilmZone-Lightmeter

## 我们自己的对照

查看了真实网页版的 `portrait.png` 和 `landscape.png`，来源是此前浏览器回归产生的合成相机截图。网页渲染用于辅助分析，不冒充 Android 真机截图。

原界面的优势是大取景、同页胶片曲线、明确 EV100／Zone 与实拍倒易律、主体参考及安全曝光。主要问题是：

- 竖屏连续／单次、冻结和设置离单手拇指较远。
- A/S/M 与连续／单次挤在一行；ISO 锁定时仍展示不可拨动的多个数值。
- 连续数值列表中，当前快门／光圈与相邻等效组合的视觉力度接近。
- 补偿刻度缺少精确的 ±1/3 EV 按钮。
- 冻结后部分控件看起来仍可点，实际却静默无效。
- 小屏安全模式在完整图形之后追加最多 190 dp 的内容，可能挤掉直方图和关键建议。
- 锁定、单次和冻结是不同语义，不能为了一个好看的按钮而错误合并。

## 第一轮改动范围

- 仅竖屏把工具栏移至底部；横屏仍保留左侧工具轨。
- 冻结时明确显示“退出冻结”；连续、单次与冻结继续各自行使原功能。
- 竖屏及较高窗口中，A/S/M 与连续／单次分开排布，连续／单次移至测光区底部。放大 EV 与当前曝光组合；横向短屏保留原有同一排模式与测量操作，并使用独立的一行 ISO，避免曝光区被固定高度控件挤掉。
- 窄屏 ISO 使用明确的选择列表和独立的锁定操作；默认锁定时整张卡片可解锁，解锁后选择与锁定均使用完整高度的区域。选单定位当前档位，并保留“自定义…” ISO／EI 输入。宽屏保留原有拨动控制，冻结时不再显示误导性的可编辑外观，同时显式提供 Android `disabled()` 语义。
- 补偿增加明确的 −／+ 1/3 EV 按钮，保留原有拖动和范围语义。步进回调执行时读取当前档位，不把上一次组合的显示值复用于快速连点；极窄用户分栏保留当前值和两个步进操作，隐藏没有足够分辨率的刻度。
- 普通竖屏在没有已保存自定义比例时，采用取景 55%、直方图 42% 的默认分配。横屏、近方形布局及 `p1/p2`、`l1/l2`、`squarep1/squarep2`、`squarel1/squarel2` 的保存值均不覆盖。
- 安全模式在“直方图”和“主体与曝光”之间明确切换，避免小屏相互挤压。图表范围状态和分析仍在外层保留。
- 主体建议的“采用”按钮使用整行宽度；实际快门、光圈、ISO、倒易律依据和不确定性提示均继续由原有计算路径产生。

本轮未引入 ND 等额外参数、自动曝光百分比评分、未点选主体的自动补偿、第三方的测光公式或美化后的精度承诺。既有的红／蓝风险提示与同帧三档切换继续保留。

## 本轮回归

- `PhotographerControlsTest` 通过实际 Android 无障碍节点操作补偿、ISO 选单和安全模式切换，并注入真实的单指平移事件；它不是只调用内部函数的替身测试。
- 补偿测试检查两次 `+`、一次 `−` 分别得到精确的 +2/3 与 +1/3 EV，冻结后按钮禁用且原值不变。
- ISO 测试检查整卡解锁、系统选单选择 ISO 200、自定义 EI 90、重新锁定到胶片以及冻结后的禁用状态。选单可以位于当前项上方或下方，测试必须双向滚动。宽屏窗口跳过仅属于窄屏卡片的检查，窄屏窗口同理跳过宽屏拨轮检查，不把跳过计作通过。
- 安全模式测试先平移图表，再切换到“主体与曝光”并返回，检查图区状态仍存在且保持平移结果；单次测量和冻结仍为独立状态。
- 现有 `HistogramGestureTest` 和 `CameraFailureTest` 继续检查双指缩放／双击复位及退出 HOLD 才应用冻结曝光的规则。

## Android 模拟器实证

环境为 Android 15 / API 35 x86_64、720×1600 像素、320 dpi，即 360×800 dp；向后一侧旋转后为 1600×720 像素，即 800×360 dp。使用系统虚拟场景相机，不是物理手机镜头或胶片成像证据。

旧版使用重新下载的正式预发布资产 `LightData-0.4.0-beta1.apk`，SHA-256 为 `C1E4F9C5DC6C8C8527E465F34F40C389540712152052D06C37485225125EF324`，签名证书与独立维护版一致。已实际查看同一模拟器上的旧版竖屏、旧版横屏、候选版竖屏、候选版横屏，以及安全曝光主体点选前后画面；没有用网页截图代替 Android 结果。

- 旧版横向短屏的直方图只有很窄的绘图带，ISO 接近系统导航区；候选版保留左工具轨，压缩重复标题、技术读数和轴高后图形可读，ISO 与当前曝光组合完整可见。
- 候选版竖屏工具栏位于底部，三个常用操作不再与模式共享一行；曝光组合和 ISO 选取均完整显示。新默认比例不覆盖保存的自定义比例。
- 实际执行了“安全 → 测光点 → 画面主体 #1”，画面显示 Zone、实际建议和退出冻结；A/S/M、补偿及 ISO 进入禁用状态，冻结时未立即改写自动曝光。

真实交互测试首先暴露了快速连点复用旧显示值和选单向二个方向滚动的问题，分别通过读取执行时当前档位、定位当前选单并覆盖双向滚动修正。测试还对比超时截图与节点，确认像素更新后仍可能保留旧的无障碍缓存；因此刷新实际点击节点并等待状态恢复，不把旧缓存算作产品断言失败。

最终完整设备测试为 **25 项：23 通过、2 跳过、0 失败、0 错误**。跳过的是窄屏窗口中的宽屏拨轮专用用例，以及需要私有拼接录制 ZIP 的可选回放，均不计作通过。测试总数和边界也记录在 `../DEVICE-TEST.md`。

## 验证边界

模拟器图形和触控结果不能代替真实手机交互。试用前仍需要重点比较大字体、冻结主体流程、已有自定义比例和真实相机触控手感。正式发版前仍需完成对应设备的相机、OpenCV、GPU、旋转与长曝光实拍检查，不能仅凭这些截图宣称所有机型更好用或胶片效果已经验收。
