# 手机镜头参数库

核验截止日期：2026-11-17。运行数据：[cameras.json](../web/data/cameras.json)；维护源文件：`tools/phone_catalog/*.json`。网页仅加载提取后的数值、适用说明和来源链接，不分发厂家手册、图片或网页正文。

本次共 **283 个型号、810 条可配置后摄参数**。Apple 按 [官方型号列表](https://support.apple.com/en-us/108044)覆盖 iPhone X（含）起全部 38 款，各代 mini、Plus、Pro Max、SE、e、Air 和 Duo 独立列出。参数条目描述原生光学路径：共用传感器的可切换路径、单枚连续变焦镜头会在资料中单独说明，不把数码裁切当作独立镜头。

## 范围与首发价

Apple 按用户要求覆盖从 2017 年 iPhone X 起全部已发布型号，不受首发价格门槛限制，以 `catalogScope: "iphone-x-onward"` 明确标记。其余品牌限定为 2022 年起、截至核验日已在中国大陆发布，且至少一种首发配置的 MSRP **严格超过 4000 元**。入门配置不足 4000 元、但高容量配置超过的机型也纳入，`priceNote` 标出符合条件的配置。已有历史支持保留稳定 ID。范围覆盖七个主品牌，不自动扩展到 REDMI、POCO、iQOO、OnePlus 等子品牌。

`launchYear`、`msrpCny`、`priceSource`、`priceNote` 记录入选依据。优先厂家发布资料；历史价格缺失时，使用发布会或首销当时的原创报道并在分品牌文档中注明。官网现价、国补、首销优惠、换购价和外币换算不当作大陆首发 MSRP。部分旧网页会更新售价，因此规格与首发价分别保留来源。

## 来源与使用限制

- 光圈、后摄配置和型号代码优先来自厂家规格、支持页面及开发者机型表。退市页面另存可用的官方网页存档链接。等效焦距优先厂家说明；厂家未列出时，原作者实机评测、相机 API 数据或媒体托管的厂家规格表分别标注。跨型号沿用或推算有单独说明。
- `source` 与 `equivalentSource` 分开：镜头设置可分别打开厂家规格及等效焦距资料，不把评测焦距声称为厂家发布值。标称值不能证明浏览器实际预览已校准，电子防抖、分辨率、画面比例和数字缩放会改变覆盖范围。
- 有证据的型号代码采用锚定匹配。华为、荣耀有些不同光学版本共用代码，这些代码保留作资料但不用于自动选型。简化 UA、常见 iPhone UA、缺失或歧义代码均要求手选；相机编号也不推断镜头种类。
- 可变光圈默认填最大光圈，并注明可调范围。用户应按实际采集模式确认手机光圈；厂家相机的机械控制不代表浏览器拥有同样能力。
- 本表是有来源的参数库，不声称覆盖所有运营商、定制包装、后加容量版本，也不代替实机取景边界和灰卡测光校准。

## 维护

编辑分品牌源文件后，在仓库根目录运行：

```powershell
python tools/build_camera_catalog.py
cd web
npm test
npm run test:browser
```

`tools/collect_phone_specs.py` 可将给定 HTTPS 规格链接的可读正文缓存到本机临时目录，辅助人工复核。网站运行时不抓取网页、不依赖第三方设备识别服务。公开数据更新必须同时核对光圈、原生焦距、型号代码和入选价格；缺项明确留空。
